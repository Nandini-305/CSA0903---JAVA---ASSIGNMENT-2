## Compile and run

Open a terminal in a task folder. Compile the Java file:

```bash
javac FileName.java
```

Run the class:

```bash
java ClassName
```

For example:

```bash
cd Task05_GenericLeaderboard
javac LeaderboardDemo.java
java LeaderboardDemo
```

The `sample-input` and `sample-output` folders contain example data/results. Benchmark timings vary by computer, Java version, background processes and JVM warm-up. Run each benchmark several times and use your own measured results in the assignment report. Do not present sample timings as universal facts.
